# ADR-005: ระบบแผนที่ GPS, ระบบสปอว์นรอบตัว และชุดควบคุมจำลองบน Simulator

- **สถานะ:** Accepted
- **วันที่ตัดสินใจ:** 2026-09-24
- **สัปดาห์หลักสูตรที่เกี่ยวข้อง:** สัปดาห์ที่ 10 (Location และ Maps)

---

## บริบท (Context)
ระบบแผนที่ใน Pokémon GO จำเป็นต้อง:
1. แสดงตำแหน่งปัจจุบันของผู้เล่นบนแผนที่จริง
2. สุ่มเกิดโปเกมอนป่ารอบตัวผู้เล่น (Procedural Spawning) ในระยะที่สามารถเดินไปแตะเพื่อจับได้
3. **ปัญหาสำคัญสำหรับการตรวจงาน:** ผู้พัฒนาและผู้ตรวจมักนั่งทำงานในห้อง/โต๊ะคอมพิวเตอร์ การต้องถือเครื่องเดินออกไปกลางแจ้งเป็นระยะทางหลายร้อยเมตรเพื่อทดสอบมอนสเตอร์เกิดใหม่เป็นเรื่องที่ไม่สะดวกอย่างยิ่ง

## การตัดสินใจ (Decision)
1. **เลือกใช้ `expo-location` ควบคู่กับ `react-native-maps`:**
   - ขอสิทธิ์และดึงพิกัดจริงผ่าน `Location.getCurrentPositionAsync()`
   - เรนเดอร์แผนที่ Interactive Map พร้อม Custom Map Marker (หมุดผู้เล่น และหมุดโปเกมอน)
2. **สร้างอัลกอริทึมสปอว์นโปเกมอนป่ารอบตัว (Procedural Nearby Spawner):**
   - เมื่อผู้เล่นอยู่ที่พิกัด $(Lat, Lng)$ อัลกอริทึมจะสุ่มเกิดโปเกมอน 3 - 6 ตัวรอบตัวในรัศมี $50 - 150$ เมตร (คำนวณผ่านพิกัดเดลต้าละติจูด/ลองจิจูดแบบทรงกลม)
3. **เพิ่มแผงควบคุมการจำลอง (Simulator Controls Panel):**
   - **ปุ่ม "Spawn Nearby":** กดปุ๊บ สุ่มสปอว์นโปเกมอนใหม่รอบตัวทันทีโดยไม่ต้องรอเวลา
   - **ปุ่ม Virtual D-Pad (เดิน 4 ทิศทาง):** กดปุ่มขึ้น/ลง/ซ้าย/ขวา เพื่อขยับพิกัดผู้เล่นทีละ 20 เมตร พร้อมขยับวงเรดาร์ตรวจจับ

## ผลลัพธ์และข้อดี (Consequences)
- **ข้อดี:**
  - ครอบคลุมเนื้อหาครบถ้วนตามสัปดาห์ที่ 10 (Permissions, GPS Coordinates, MapView, Custom Markers)
  - สะดวกสบายต่อการนำเสนอผลงาน (Presentation) และการตรวจงานบนเครื่องจำลอง
  - สามารถสลับไปใช้ GPS จริงได้อัตโนมัติเมื่อนำไปเปิดบนมือถือกลางแจ้ง
- **ข้อพิจารณา:**
  - บน Expo Web หรือกรณีไม่มี Google Maps API Key ให้ตั้งค่าใช้ OpenStreetMap / Apple Maps ตามแพลตฟอร์มมาตรฐานของ react-native-maps
